Experimental private vkd3d-proton diagnostic patch
================================================

Base: HansKristian-Work/vkd3d-proton
71cae091b06571e51446cf2a937f0b04c237c04d

Opt-in: VKD3D_UNSTABLE_BARYCENTRICS=1 (default off).
Adds a diagnostic opt-in to the existing AMD compatibility path, retaining
AMD vendor, explicit-vertex-parameter extension and subgroup-size guards.
It does not enable the unrelated VRS compatibility feature.

This is a backend experiment, not a VIctory source fix or a verified replacement
for native fragment barycentrics. The converter's existing fallback has unstable
vertex ordering and incomplete centroid/per-sample handling. See the investigation
report for actual test results before using it.

The modified upstream file is LGPL-2.1-or-later; retain its upstream licence
and copyright when distributing a patched backend. This patch adds no game data.

Apply to the exact backend base with:
    git apply --check /path/to/this-file.txt
    git apply /path/to/this-file.txt
